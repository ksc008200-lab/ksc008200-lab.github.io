개인정보처리방침

시행일 2026년 10월 23일 · 앱 이름 comment-alarm · 운영자 wowgood

1. 어떤 정보를 다루나요

운영자 본인 계정의 영상에 달린 공개 댓글 정보(댓글 내용, 작성자 표시 이름, 작성 시각, 영상 제목과 링크)와, 운영자 본인 계정의 기본 정보(채널·계정 ID)만 다룹니다.

2. 왜 쓰나요

운영자에게 새 댓글을 알려 주고, 운영자가 직접 쓴 답글(또는 운영자가 미리 정해 둔 자동 답글)을 해당 댓글에 등록하기 위해서만 씁니다. 광고, 판매, 분석, 프로필 수집에는 쓰지 않습니다.

3. 어디에 보관하나요

이미 알린 댓글의 ID만 운영자 개인 컴퓨터에 저장합니다. 댓글 내용은 운영자 본인의 텔레그램 대화방으로만 전달됩니다. 서버나 데이터베이스에 따로 모아 두지 않습니다.

4. 다른 곳에 주나요

제3자에게 판매하거나 제공하지 않습니다. 알림 전달에는 텔레그램을, 답글 등록에는 YouTube·Instagram·TikTok의 공식 API를 사용합니다.

5. 구글 사용자 데이터 (YouTube API)

이 앱은 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다. 구글 사용자 데이터 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수합니다. 연결 해제는 Google 계정의 서드 파티 연결 관리에서 할 수 있습니다.

6. 삭제 요청

댓글 작성자는 각 플랫폼에서 자신의 댓글을 삭제할 수 있습니다. 이 앱 관련 문의나 삭제 요청은 아래 이메일로 보내 주세요.
